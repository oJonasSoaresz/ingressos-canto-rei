Conectar ao Supabase

Faça isso uma vez em cada aparelho (celular da portaria, computador etc.). Os dados ficam salvos neste navegador.

Código para criar a tabela no Supabase

No Supabase, abra SQL Editor, cole o código abaixo e clique em Run.

create table if not exists ingressos (
  id uuid primary key default gen_random_uuid(),
  nome text not null,
  telefone text,
  evento text,
  lote text,
  usado boolean not null default false,
  usado_em timestamptz,
  criado_em timestamptz not null default now()
);

alter table ingressos enable row level security;

create policy "acesso do app" on ingressos
  for all using (true) with check (true);

Emitir ingresso

Depois de confirmar o PIX, preencha o nome do pagante. Cada ingresso vale para uma entrada.
